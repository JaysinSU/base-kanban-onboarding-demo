# Base Kanban Onboarding Demo

*Interactive iPhone-sized Base Kanban demo with AI prompt onboarding.*

一个以 iPhone 画布展示的 Base 需求看板交互 Demo。看板示例为 “Q1 2023 Planning Requirements List”，包含按负责人分组的任务列，以及任务的预计完成日期、延期状态、重要紧急程度、进展和任务情况总结。

底部输入框展示 AI 问数引导动效和示例问题；可输入并提交问题，搜索和筛选控件提供本地交互反馈。点击添加按钮或列内的“添加记录”，会打开添加面板；输入任务名称后可将记录加入对应看板列。

## 本地打开

在浏览器中直接打开仓库根目录的 `index.html`，即可查看和操作这个静态演示页面。
